Tutorial Menampilkan Gambar (Tag <img>)

Tag <img> adalah tag kosong (tidak memiliki tag penutup) yang digunakan untuk menyisipkan gambar ke dalam halaman web.

1. Gambar dari File Lokal

Pastikan file gambar (contoh: foto.jpg) berada di dalam folder yang sama dengan file HTML Anda.

2. Gambar dari Internet

Anda juga bisa mengambil gambar langsung dari internet dengan memasukkan link URL lengkap pada atribut src.
